About Project

Student Management & Attendance Portal

This is a Web Technology project.The Student Attendance Management System is a web-based application developed using HTML, CSS, and JavaScript. It allows users to manage student details, mark daily attendance as Present or Absent, and automatically calculate attendance percentages,having student details,calculate total class attendence percentage ,etc.

22 Features

  1. Search student
  2. Add student
  3. Edit details
  4. Delete student
  5. Complete profile
  6. Present/Absent attendance
  7. Attendance percentage
  8. Subject-wise marks
  9. Percentage calculation
  10. Automatic grade
  11. Student ID
  12. Parent/guardian information
  13. Course & semester
  14. Profile photo
  15. Active/Inactive status
  16. PHP backend data storage
  17. Dashboard statistics
  18. Responsive design
  19. Gold + black theme
  20. Student profile card
  21. Attendance history
  22. Academic performance
